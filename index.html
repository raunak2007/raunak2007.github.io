Hi, I'm Raunak

I'm studying CS at Carnegie Mellon (SCS '29). Mostly I find the same bug over and over: an operation that returns success while quietly doing the wrong thing. A cache that hands back the wrong asset. A copy that copies a file onto itself. A risk statistic that returns a plausible number where the math is undefined. Six of them so far, in codebases I didn't write.

The research version of the same question is whether a system's reported score still tracks what it was built to measure. I build agent evaluation benchmarks, advised by Prof. Amarnath Gupta at UCSD, and I'm a Fall 2026 SPAR fellow working on deception in language models.

Day to day I'm a software engineering intern at Twinly, building agent features for a desktop assistant in C#/.NET 9, and backend & database lead at ScottyLabs, where I own 85 RPC functions across ~19,000 lines of SQL. Published at AMIA 2024 (1st author) and ACM CHI 2024.
