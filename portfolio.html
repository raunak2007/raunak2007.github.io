Selected work

Full-stack systems, and the models inside them.

rfsim: research field simulator

Flask · React · Neo4j

A full-stack simulator of research-field dynamics: a Flask backend over a Neo4j graph of OpenAlex bibliometric data, a React frontend, and a discrete-event engine using k-truss decomposition and spectral clustering. Ships with a one-command bootstrap and a Makefile for clean handoff.

CRN-Bench: do LLM agents run controlled experiments?

Python · LLM APIs · advised at UC San Diego

A benchmark that drives LLM agents against a stochastic simulator and scores whether they hold variables fixed or read noise as signal. Scripted baselines bound the false-positive range before any model is run, so a real finding is separable from a lucky one. Built on a 21-parameter simulator over the OpenAlex citation graph.

  • 0 / 15 confabulated at 50 calls
  • 6 / 15 confabulated at 200
  • 21 simulator parameters

Image memorability with a calibrated trust layer

PyTorch · CLIP ViT · Modal

Predicts LaMem image memorability at the human consistency ceiling, then adds a layer that reports when a prediction should not be trusted. Split-conformal calibration gives near-exact coverage, and an out-of-distribution gate catches inputs the model's own variance cannot.

  • 0.699 Spearman (ceiling ≈ 0.68)
  • 0.905 calibrated coverage
  • 0.93 OOD AUROC
github.com/raunak2007/lamem-memorability

Reported vs. true quality in SkyDiscover

LLM evaluation · independent research

A dead-parameter injection experiment on UC Berkeley's LLM-driven search framework. Perturbing the evaluator's score in train mode only, with the framework's own test mode held out, surfaced a reward signal that kept climbing while true quality had already plateaued. A metric that looked real and was not.
